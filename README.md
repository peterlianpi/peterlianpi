## 👋 About Me

I build meaningful technology for people and communities. My current focus is **preserving the Tedim Zolai language** through AI — building the first fully capable AI second brain for the Zomi people.

> 💡 **Mission:** Digitize, standardize, and preserve the Tedim Zolai language through automated data pipelines, high-purity bilingual datasets, and fine-tuned LLMs.

**[peterlianpi/zolai-ai](https://github.com/peterlianpi/zolai-ai)** — Open-source NLP toolkit for the Tedim Zolai (Tedim Chin) language.

| Asset | Details |
|-------|---------|
| 🗣 Language | Tedim Zolai · Tibeto-Burman · ~500k speakers |
| 📚 Dictionary | 152k ZO↔EN entries |
| 📖 Bible corpus | TB77, TBR17, Tedim2010 ↔ KJV (93k+ parallel verses) |
| 🤖 Training data | ~2M deduplicated Zolai sentences (v3) |
| 🧬 Model | [Qwen2.5-3B LoRA](https://huggingface.co/peterpausianlian/zolai-qwen2.5-3b-lora) · QLoRA 4-bit · Kaggle T4 |
| 🏗 Stack | Python · FastAPI · Next.js 16 · Prisma · Kaggle · HuggingFace |
